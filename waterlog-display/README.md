# 黄岩区城市内涝监测 · 两页展示大屏

一个**纯展示**的水位监测大屏，独立于 `waterlog-v3` 业务系统：无登录、无后台管理、无治理页面，只做两页轮播的现场大屏。所有数据来自本地确定性模拟，**非真实观测**，仅用于演示交互与视觉。

## 运行

```bash
npm install
npm run dev        # http://127.0.0.1:8300
npm run build      # 类型检查 + 生产构建到 dist/
npm run preview    # 预览 dist/
```

验证：

```bash
npm test           # 11 项：数据确定性、12h 预测/置信带、评估、联动规则、轮播
npm run test:ui    # 19 项：Playwright 实测两页元素、点击联动、数据自动变化并截图到 shots/
```

## 两页内容

| 页面 | 路由 | 布局 |
| --- | --- | --- |
| 全域态势 | `?page=1` | 中间真实黄岩区地图（圆点可点）；左：预警日历 / 运行概况 / 站点列表；右：预警列表 / 未来峰值排行 / 站点轮换说明 |
| 预测专屏 | `?page=2` | 顶部站点切换条；主：单站观测 + 12h 预测曲线与四个预见期卡片；侧：全站预测 / 预测-实测对照 / 近 6 小时降雨；底部：12h 峰值预测表 |

- 默认每页 3 秒自动切换（`?interval=秒数` 可覆盖，最小 3 秒）；选中站点每 11 秒自动轮换。
- `?paused=1` 冻结轮播与站点轮换（数据时钟仍走），便于静态截图或人工讲解。
- 顶栏「暂停/继续」按钮可现场切换自动播放。

## 交互（所有部件协同更新）

地图圆点、站点列表、预警列表、排行条、站点切换条、预测表行——任一处点击都会更新同一个 `selectedId`，地图高亮、详情浮层、主预测图、四个预见期卡片、底部表格高亮与页脚播报同步跟随。

## 数据模拟（`src/data.ts`）

- 模拟时钟：每 2.2 秒推进一个 5 分钟步（`START=2026-07-18 02:00 +08`），页面数字随之刷新。
- 确定性：基于 `(step, siteIndex)` 的哈希 + 多频正弦 + 阵雨脉冲，无 `Math.random`，同一 `step` 永远得到同一快照。
- 雨强 ~3–90 mm/h 的阵雨场次；水深 ~0.27–0.69 m，跨越蓝/黄/橙/红四级阈值，颜色随 `step` 切换。
- history 73 点（过去 6h）；forecast 145 点（now 至 now+12h，含 1/3/6/12h 预见点与置信带）；evaluation 25 点（提前 1h 预报对照，每 30min）。
- 阈值：蓝 0.20 / 黄 0.35 / 橙 0.50 / 红 0.65 m；水深为绝对水位减基面（baseLevel=0）。

## 结构

```
src/
  App.tsx          两页布局、轮播/暂停/站点协同、详情浮层
  main.tsx         入口
  styles.css       浅色天气预报风、悬浮卡片、倾斜地球背景、动效
  data.ts          确定性模拟数据（含测试）
  view.ts          等级/时间/格式工具
  Charts.tsx       SVG 图表：趋势/全站/雨量/预测实测/微趋势
  StationMap.tsx   Leaflet 真实底图 + 可点圆点
  geo.ts           高德 GCJ02 瓦片坐标转换
  presentation.ts  轮播规则与 URL 参数
scripts/verify-ui.mjs   Playwright UI 实测
shots/                  UI 实测截图（交付证据）
```

## 说明

- 地图使用在线瓦片，离线环境底图可能空白，但圆点、交互与统计不受影响。
- 本项目刻意不接后端 API；`vite.config.ts` 中的 `/api` 代理为后续可选接入保留。
- 生产旧系统 `114.55.31.135:8200` 与本地 `waterlog-v3` 均未受影响。
