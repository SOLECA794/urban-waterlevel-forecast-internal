# 黄岩区城市内涝监测 · 两页展示大屏

一个**纯展示**的水位监测大屏，独立于 `waterlog-v3` 业务系统：无登录、无后台管理、无治理页面，只做两页的现场交互大屏。**页面不自动轮播，全部由人工点击切换**；数据每 2.2 秒自动波动推进。所有数据来自本地确定性模拟，**非真实观测**，仅用于演示交互与视觉。

## 运行

```bash
npm install
npm run dev        # http://127.0.0.1:8300
npm run build      # 类型检查 + 生产构建到 dist/
npm run preview    # 预览 dist/
```

验证：

```bash
npm test           # 单元测试：数据确定性/自适应波动/3-6-12h 差异/评估/图表
npm run test:ui    # Playwright 实测两页元素、手动换页、点击联动、数据自动变化并截图到 shots/
```

## 两页内容

| 页面 | 路由 | 布局 |
| --- | --- | --- |
| 全域态势 | `?page=1` | 中间真实黄岩区地图（圆点可点）；左：预警日历 / 运行概况 / 10 站点列表；右：预警列表 / 未来峰值排行 / 联动站点速览 |
| 预测专屏 | `?page=2` | 左：10 个监测点列表（水深/雨强/微趋势/等级）；右：选中站点的详情头（当前水深/1h/12h 峰值/峰值时刻/雨强/阈值）+ 12h 观测与预测主图 + 预测-实测对照 / 近 6h 降雨两图 |

- **无自动轮播**：只通过顶栏「全域态势 / 预测专屏」Tab 手动换页（不设 `interval`、无轮播进度条）。
- 「暂停数据 / 继续数据」按钮只冻结/恢复模拟数据时钟，不影响页面切换。
- 10 个监测点（HY01–HY10，黄岩区），不多不少。

## 交互（所有部件协同更新）

- **全域态势页**：地图圆点、站点列表、预警列表、排行条、联动速览卡——任一处点击都会更新同一个 `selectedId`，地图高亮、站点详情浮层、速览卡的 3/6/12h 数值与页脚播报同步跟随；详情浮层可关闭。
- **预测专屏页**：左侧 10 站点列表为唯一导航——点击任一站，右侧详情头、12h 观测与预测主图、预测-实测对照、降雨图全部切换到该站，实现「以站点为中心的点击联动」；采用 master-detail 两栏，非堆积视觉，不依赖纯数据表格。

## 数据模拟（`src/data.ts`）

- 模拟时钟：每 2.2 秒推进一个 5 分钟步（`START=2026-07-18 02:00 +08`），页面数字持续刷新。
- 确定性：基于 `(step, siteIndex)` 的哈希 + 多频正弦 + 阵雨脉冲，无 `Math.random`，同一 `step` 永远得到同一快照。
- 相邻 step 水位/雨强明显变化；10 站同刻水深跨多个预警等级；3h/6h/12h 预见期差异明显（科研绘图风区间图直观呈现）。
- 阈值：蓝 0.20 / 黄 0.35 / 橙 0.50 / 红 0.65 m；水深为绝对水位减基面（baseLevel=0）。
- history 73 点（过去 6h）；forecast 145 点（now 至 now+12h，含 3/6/12h 预见点与置信带）；evaluation 25 点（提前 1h 预报对照，每 30min）。

## 结构

```
src/
  App.tsx          两页布局、手动换页、详情浮层、全组件协同
  main.tsx         入口
  styles.css       浅色天气预报风、倾斜地球背景、科研绘图与交互反馈动效
  data.ts          确定性模拟数据（含测试）
  view.ts          等级/时间/格式工具
  Charts.tsx       SVG 图表：趋势/雨量/误差/站点微趋势（科研绘图风：网格/置信带/阈值线/散点）
  StationMap.tsx   Leaflet 真实底图 + 可点圆点
  geo.ts           高德 GCJ02 瓦片坐标转换
  presentation.ts  页面路由参数解析
scripts/verify-ui.mjs   Playwright UI 实测
shots/                  UI 实测截图（交付证据）
```

## 说明

- 地图使用在线瓦片，离线环境底图可能空白，但圆点、交互与统计不受影响。
- 本项目刻意不接后端 API；`vite.config.ts` 中的 `/api` 代理为后续可选接入保留。
- 生产旧系统 `114.55.31.135:8200` 与本地 `waterlog-v3` 均未受影响。
